How this works for real

      
Read-only feeds from the control-room alarm software and vehicle tracking land in one Postgres warehouse every minute. A Kimball model joins each call-out to client, property, town, vehicle and officer. This page and the questions run on that model, inside South Africa, on your own server if you prefer.
